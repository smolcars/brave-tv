# Compact Ambient footer

Original request: cleaner, nicer Home footer, especially its text; use the official GitHub icon and reduce the height. The user invoked Impeccable redesign. This is a local redesign inside the established native TV Ambient world, not a replacement identity.

Mode: Operate. Preserve the selected scenic background, forest tones, system TV sans, mint focus, exact product description and credits, native navigation, private behavior and project destination.

**THESIS:** Give the browser's scenery and primary search room by making Home's secondary footer and navigation compact.

**OWN-WORLD:** Inherit the user-selected Ambient world in `.impeccable/surfaces/tv-home-and-menu.md`: forest surfaces, warm white, mint focus, native TV sans and the credited landscape.

**STORY:** Search remains the initial target; native Home, Tabs, Favorites and live Phone actions remain available above, with the project source action below. Native data and privacy owners remain authoritative.

**FIRST VIEWPORT:** Two-line footer hierarchy with a quiet official GitHub mark; compact top navigation pills that fit their labels. The actual native foreground remains scrollable and the footer reserves its own height at enlarged text.

**FORM:** Local extension of the established Ambient surface. Per new-work's narrow-request/local-extension rule, no new roll is run. The inherited contract records its original user selection and pre-existing engine seed limitation with `.impeccable/questions/ambient-seed-check.txt` and `tv-options.json` as corroboration.

**FINISH:** Native captures, focused D-pad checks, independent finish review, and matching design documentation. No HTML/CSS detector applies to native Kotlin.

Composition: a two-line left stack, with a warm-white 12sp regular description above quieter 11sp regular upstream credits. The photographer credit shares the second row toward the right. Attribution flows to more lines when space is insufficient. A trailing 56×48dp quiet GitHub action uses the official 2026 Invertocat vector with its original geometry and aspect ratio, the existing accessible GitHub name, and native focus/activation.

Geometry: 40dp side insets, 4dp top and 12dp bottom, 20dp between the text and action, 2dp between text lines. At baseline 960×540dp TV size the 48dp action determines a 64dp footer, versus the previous 80dp. Actual footer height remains reserved outside the scrolling Home content.

User follow-up: Home, Tabs and Favorites selection pills are too big. Header navigation now uses intrinsic-width buttons in a FlowRow with 8dp gaps, instead of weighted equal-width columns. Compact labels lose their extra 8dp top/bottom inner padding; navigation retains a 48dp minimum height, existing TV button outer padding, 14sp medium labels, live Phone state, selected Home semantics and mint focus. Status labels and enlarged text may wrap naturally. Other action buttons keep their existing presentation.

Review scope: footer hierarchy, readability, 1080p layout at 1.0 and 1.3 font scale, official asset identity, scaled wrapping, and GitHub remote activation. Unrelated surfaces remain outside scope. This code-led local change has no decision comp or raster QUALITY BAR card. No detector runs for native Kotlin UI.
